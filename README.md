# 문학과 영상 · 각색 인터뷰와 비교 토론

고등학교 2학년 '문학과 영상' 수행평가용 AI 융합수업 웹앱입니다. 학생 개인이 자신의 각색 영상 작품을 두고 다음 활동을 하고 기록을 제출합니다.

1. **작품 정보**: 원작, 원문 발췌, 줄거리, 각색 포인트, 연출 기법, 찬조 출연
2. **AI 인터뷰**: 원작 작가 → 영화 평론가 → 영화제 기자, 인터뷰어마다 질문 3개 (주제를 나누고 앞 인터뷰를 참고해 중복 질문 방지)
3. **AI 각색 비교**: 같은 원작 장면을 AI가 시나리오로 각색, 학생 각색과 비교
4. **토론·성찰**: 논제, 입장, 근거, AI 반론과 재반박, 토론 후 성찰
5. **제출**: 체크리스트 확인 후 제출, 교사는 '제출 현황' 탭에서 확인하고 CSV로 내려받기

## 실행 환경

이 페이지는 **claude.ai 아티팩트 런타임**에서 동작하도록 만들었습니다. 다음 기능은 `window.claude.use()`로 claude.ai가 제공합니다.

| 기능 | 용도 |
|---|---|
| `sample` | AI 인터뷰, AI 각색, 질문 생성 (보는 사람의 Claude 계정 사용량 사용) |
| `db` | 학생 기록 저장, 교사 제출 현황 |
| `user` | 학생 구분, 교사(편집 권한자) 확인 |
| `downloads` | .txt / .csv 내려받기 |

따라서 GitHub Pages 등 다른 곳에서 `index.html`을 열면 화면은 보이지만 **AI 기능과 저장·제출은 작동하지 않습니다.** 수업에서는 claude.ai 아티팩트 링크를 학생에게 공유해 사용하세요 (공유 권한: 참여자 이상).

이 저장소는 소스 보관과 공유를 위한 것입니다.

## db 권한 규칙

```json
{
  "db": {
    "rules": [
      { "path": "submissions", "read": "admin", "write": "owner" },
      { "path": "submissions/{self}", "read": "view", "write": "interact" }
    ]
  },
  "user": {}, "sample": {}, "downloads": true
}
```

학생은 자기 기록(`submissions/<본인 id>`)만 읽고 쓰며, 교사(소유자·편집자)는 전체를 읽습니다.
